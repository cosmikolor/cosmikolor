# Hi, I'm Shining Wang 👋

Electrical Engineering student at **Columbia University** (B.S. 2029). I build hardware and autonomy for robots and drones: PCBs, radar, sensor payloads and GPS-denied navigation.

### What I'm working on
- **Hardware Engineering Intern @ BotBlox:** compact Ethernet PCBAs for drones, and characterising 77 GHz FMCW radar (drone detection at ~50 m).
- **Researcher @ Columbia MPLAB:** a 4-layer KiCad board to characterise a TI C2000 microcontroller at cryogenic temperatures (~77 K). → [cryogenicControllerBoard](https://github.com/cosmikolor/cryogenicControllerBoard)
- **Co-Lead, AQUAS (Columbia Robotics Club):** a BlueBoat/BlueOS autonomous surface vehicle for harmful algal bloom monitoring with Lamont-Doherty Earth Observatory. It runs autonomous sampling missions in Central Park every two weeks, and we're migrating the payloads to a networked ESP32 architecture.

### Highlights
- 🏆 **Top 5 at Stanford DroneHacks 2026:** autonomous GPS-denied drone navigation on PX4 + NVIDIA Jetson. I built a ROS 2 localizer that matches the live stereo point cloud to a 3D model of the course (cutting drift from 35 cm to 2 cm in simulation), a localization simulator, and the team's flight-test and pre-flight tooling (30+ commits). → [Navless](https://github.com/RaagaSundar/Navless)
- 📄 **IEEE publication (MIT URTC 2024):** metrics for optimising LiDAR scan parameters, using an ICP-based SLAM pipeline on Boston Dynamics' Spot. → [paper](https://ieeexplore.ieee.org/document/10937609)
